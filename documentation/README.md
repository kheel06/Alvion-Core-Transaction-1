## 👥 System Roles

The Hospital Core System supports the following roles:

1. **ADMIN / HOSPITAL ADMINISTRATOR**
   - Full system access and configuration
   - User and role management
   - System maintenance and reporting

2. **DOCTOR**
   - Patient care and consultations
   - Prescriptions and lab orders
   - Medical record management

3. **STAFF** (Nurse, Clerk, Ward Staff)
   - Patient registration
   - Triage and vital signs
   - Queue and bed management

4. **PATIENT** (Portal User)
   - Appointment booking
   - Medical records access
   - Online payments

5. **RECEPTIONIST** (Front Desk)
   - Patient registration
   - Appointment management
   - Queue coordination

6. **FINANCE STAFF**
   - Billing and SOA generation
   - Payment processing
   - Insurance claims management
